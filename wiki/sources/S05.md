# S05 教育部：大量傷患處置與檢傷分類

- 檔案：`raw/05 - 大傷傷患檢傷原則-教育部研習.pdf`（48 頁投影片）
- 性質：檔名標示為「教育部研習」；開場問題是「為什麼我(學校)需要學會檢傷?」〔S05 p.1〕，由此推測對象為學校人員（推論，非原文）
- 在本 Wiki 的角色：**白話、台灣用語的基礎來源**。本身未附參考文獻。

## 核心主張

1. 大量傷患現場的目標是「以有限的人力、資源，在最短的時間救治最多的病人」〔S05 p.3〕。→ [[大量傷病患]]、[[檢傷分類]]
2. 多重傷病患與大量傷病患的定義不同，「先救誰」的答案也不同：多重先救最嚴重的病患，大量先救有機會活下來的〔S05 p.6–7〕。→ [[大量傷病患]]
3. 四色分類：紅、黃、綠、黑〔S05 p.4〕。→ [[四色分類]]
4. 以 START 流程進行現場初級檢傷〔S05 p.20、p.22〕。→ [[START]]
5. 例外：雷擊、低體溫者雖判黑但優先救〔S05 p.23〕。→ [[逆向檢傷]]
6. 第一反應者以自身安全為第一優先〔S05 p.9、p.15〕。→ [[第一反應者原則]]
7. 現場只做立即性處置（止血、維持呼吸道）〔S05 p.27〕。→ [[現場立即處置]]
